ComplianceCore workflow and page audit - 4 November 2026

Comparison with CIASecured
Applied: preservation of unsaved answers; section navigation without resetting
drafts; persistent server validation and permission/connection errors; retry using
current inputs; actionable assessment-review blockers; people-list recovery.
ComplianceCore retains organisational assessments, controls, evidence, treatment,
independent assurance and monitoring. No consultancy implementation questionnaire,
client scope approval, quotation or purchased delivery-phase flow was imported.

Reproduced and fixed
1. Saving a stakeholder interview invalidated the assessment query. The scope
   editor's hydration effect replaced unsaved scope with the saved server value.
2. The application shell keyed each page by its entire query string. Changing an
   assessment step remounted its editor and discarded unfinished answers.
3. Assessment write failures relied on transient toasts with generic validation
   text. Consultation/risk forms now retain visible failures and offer Retry.
   Field-specific errors can focus named fields, including inside collapsed panels.
4. Independent-review prerequisites were static text. Each check now opens its
   assessment step. Active-member load failures offer a retry; review requirements
   and the team/roles recovery route are visible.

Drafts stay only in component memory, scoped by user, organisation and framework.
They survive step changes and background refreshes. Save before closing/reloading.
A saved answer is confirmed by a successful server response, then checked by
reopening. Independent approval still belongs to the saved assessment records;
edits reopen readiness through the existing server rules.
